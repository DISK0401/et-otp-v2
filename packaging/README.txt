et-otp-v2 portable edition

No installation is needed. Extract the archive and start the launcher in the folder.
The Java runtime (Eclipse Temurin JRE) is bundled in the "runtime" folder.

How to start
- Windows: double-click et-otp-v2.bat
- macOS:   double-click et-otp-v2.command. If it does not start, run in Terminal: sh et-otp-v2.command
- Linux:   run in a terminal: sh et-otp-v2.sh

Settings
The settings are saved to .et-otp.properties in your home folder. To carry the settings
with this folder (e.g. on a USB drive), follow the comment in the launcher file.

If you use this on a company or organization computer, check your organization's software
policy first.

et-otp-v2 ポータブル版

インストールは不要です。展開したフォルダの中のファイルを起動するだけで使えます。Java の実行環境（Eclipse Temurin の JRE）は runtime フォルダに同梱しています。

起動の方法
- Windows: et-otp-v2.bat をダブルクリックします。
- macOS: et-otp-v2.command をダブルクリックします。起動できない場合は、ターミナルで sh et-otp-v2.command を実行してください。
- Linux: ターミナルで sh et-otp-v2.sh を実行します。

設定の保存先
設定はホームフォルダの .et-otp.properties に保存されます。USB メモリなどで持ち運ぶ場合は、起動用のファイルの説明に従って、設定をこのフォルダに保存するように変えられます。

会社や組織のパソコンで使う場合は、ソフトウェアの利用について社内のルールを確かめてから使ってください。

同梱している JRE のライセンスは runtime/legal フォルダにあります。et-otp-v2 のライセンスは GNU General Public License v2.0 only です。
